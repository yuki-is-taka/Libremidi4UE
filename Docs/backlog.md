# Backlog — Libremidi4UE's open TODO ledger

The single list of this unit's OPEN future work. Lifecycle: `idea → designed → done`
(terminal alternate `dropped`). Maintained as a co-output of work (see
[`../../../Docs/_capture-protocol.md`](../../../Docs/_capture-protocol.md)), not separate
bookkeeping. Shipped rows leave Active; the ADR/commit is the permanent record.
